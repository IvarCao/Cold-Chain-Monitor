# Hardware bill of materials

- ESP32-DevKitC-VIE development board (user-selected SKU: 1965-ESP32-DEVKITC-VIE-ND)
- DHT11 three-pin module
- DS3231 RTC breakout and compatible backup battery
- Breadboard and jumper wires
- USB data cable
- Optional multimeter

No microSD module is used. Offline readings are queued in ESP32 internal flash using LittleFS. Verify exact module pin labels, voltage limits, and onboard pull-ups before wiring.
